# Brand and Interface colours only on chrome, one green per card

The UI uses Artizen's Brand (Algae, Moss) and Interface colours only; Illustration colours (Reef, Gravel, Coral, Truffle, Lavender) stay off chrome so that green on a fund card only ever means fit. Algae cannot carry white type (2.1:1 on white) and Moss can (6.9:1), so every filled element that carries type uses Moss, and a card uses one green rather than Algae on the meter and Moss on the badges. Bootstrap's `btn-dark` and `btn-outline-dark` are retargeted once onto Artizen's Primary and Secondary roles instead of being overridden per call site. Relationship-history badges (Applied, Curated, Funded) fill with UI Alert, the other Interface colour that carries white type (about 4.8:1), so history never borrows fit's green. The notes behind the tokens live as comments beside them in `src/styles.css`. Sources: commits 1dc24fe, 47ee783, 6168e37, 38e1020, b69622f, 6e0df1e.
