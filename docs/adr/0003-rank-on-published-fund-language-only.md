# Rank on published fund language only

The ranker reads each Fund's published description and eligibility text, plus reviewed project-agnostic facets and distinctive core concepts. Curation history, availability and activity are display context only and never affect rank or score, and the checked-in ontology and vocabulary corrections under `src/matching/` must not encode project-specific rules or eligibility claims. Results are therefore thematic fit and say so; they are never eligibility decisions. Source: MATCHING.md.
